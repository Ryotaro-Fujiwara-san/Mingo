# Mingo 仕様書

## 1. 製品概要

Mingo は、**AI との自然な会話**を通じて実践的なスピーキング力を鍛える英語（多言語）学習プロダクト。

ボタン操作を起点としない自然なターンテイキングと、その場での文法・発音フィードバックにより、「会議で発言できない」「面接が怖い」といった**実戦に近いプレッシャー下での発話**を安全に練習できる。相手 AI のパーソナリティや状況を細かく設定できるため、面接・会議・交渉などシーンに合わせた会話練習が可能。

---

## 2. ターゲットと課題

| ターゲット | 解決したい課題 |
| --- | --- |
| 外資・グローバル企業で働く社会人 | 英語の会議で一言も発言できない |
| 転職・就活で英語面接を控える人 | 英語面接が怖い／準備できない |
| 発音に自信がない学習者 | 発音が通じない、リンキングが不自然 |
| 英語以外の言語学習者 | 実践的な会話練習の場がない |

---

## 3. コア機能

### 3.1 リアルタイム会話・文字起こし
- ユーザーの発言と AI の返答を、**両方リアルタイムで文字起こし**して画面に表示する。
- 会話の流れを目で追えるため、聞き取れなかった箇所もその場で確認できる。

### 3.2 割り込み（インタラプト）対応
- AI が話している途中でも、ユーザーが**自由に割り込んで発言**できる。
- ボタンを押さずに会話が始まり・続く、自然なターンテイキングを実現する。

### 3.3 その場フィードバック
- **文法**：ユーザーの発言に誤りがあれば、訂正文を表示する。
- **発音・リンキング**：発音やリンキング（音のつながり）が不自然な場合、何がどうおかしいかを解説文で提示する。
- 発音は音素ごとに 0〜100 で採点する（精度評価）。

### 3.4 ロールプレイ設定
- 相手 AI の**パーソナリティ・状況を細かくカスタマイズ**できる。
  - 例：「厳しい外資の面接官」「フランクな同僚」「急いでいるクライアント」など。
- シーン設定（会議・面接・雑談・交渉など）に応じて相手を作り込める。

### 3.5 学習定着システム（ハイライト習得）
- ユーザーがハイライトした単語・イディオムは、相手 AI が返答内で**赤字で積極的に使用**する。
- ユーザーがそれらを使った文を多く発話するほど「**習得した**」とみなし、赤字表示が自然に消えていく。
- 「単語との出会い → 反復露出 → 自分で使う → 定着」を会話の中で完結させる、間隔反復に近い設計。

### 3.6 深掘り解説 ※ Step 5 / 6（MVP 後回し）
- AI のセリフをクリックすると、**文法・イディオム・類似表現**まで深掘り解説を表示する。
- 「日本語でこう言いたい」と入力すると、**自然な英訳と文法ヒント**を返す。
- 需要検証で ChatGPT / DeepL による代替性が高いと判断したため、MVP では実装しない（§10 ロードマップ「後回し」参照）。

### 3.7 補助機能
- **リピート再生**：AI の発話を聞き直せる。
- **単語タップ発音**：単語をタップすると、その発音が再生される。※ Step 7（MVP 後回し）

### 3.8 多言語対応 ※ Step 11（MVP 後回し）
- 英語に限らず、複数言語の学習に対応する。
- MVP は英語 × 面接ロールプレイに集中し、勝ち筋が見えてから他言語へ拡張する。

## 4. 競合との差別化ポイント

MVP で勝負する軸（順に優先）:

- **ボタン不要の割り込み型ターンテイキング**：実戦に近い発話プレッシャーを再現。ChatGPT 英会話の「速度が合わない／相槌がない」不満に直撃。
- **細かく作り込めるロールプレイ × 面接特化**：相手のパーソナリティ・状況を自由設定し、特に**英語面接（外資・転職）**で履歴書連動の深掘り質問まで踏み込む（§6.1 を MVP 段階で前倒し検討）。
- **音素別発音スコア + linking 検出**：「通じない不安」を数値で解消。ELSA Speak と同領域だが、面接ロールプレイのフィードバック内に統合することで差別化。
- **ハイライト習得システム**：出会いから定着までを会話内で完結させる独自の学習ループ（Step 8）。

## 5. 要検討事項（実装前に決めるべき点）

1. **習得判定ロジック**
   - 何回／どの精度で使えば「習得」扱いとするか。
   - 単純な使用回数のみか、文法的に正しく使えたかも評価対象に含めるか。
   - 判定基準によって体験が大きく変わるため、初期からルールを確定させる。

2. **会話 UX の品質**
   - 割り込み処理、応答遅延の最小化、自然なターンテイキング。
   - ここの UX が崩れると体験全体が一気に陳腐化するため、本プロダクトの肝。

3. **用語統一**
   - 「リンギング」ではなく **linking（リンキング）** が正しい表記。UI 文言で統一する。

## 6. 将来的な拡張

### 6.1 レジュメ・写真のアップロード
- ユーザーが**レジュメ（履歴書・職務経歴書）や写真**をアップロードできるようにする。
- レジュメをもとに、AI 面接官が**実際の経歴に沿った質問**を投げる、よりパーソナライズされた面接ロールプレイを実現する。
- 写真は会話の話題提供（写真について説明する練習）や、シーン設定の補助素材として活用できる。

> 検討点：アップロードした個人情報（レジュメ・写真）の保存範囲・利用目的・削除手段を明確にし、プライバシーポリシーと UI 上の同意フローを整備する。

### 6.2 ネイティブアプリ化
- 現行の Web ベースから、**スマホアプリ（iOS / Android）**への展開を予定。
- マイク・音声処理との親和性、プッシュ通知による継続利用、オフライン復習などアプリならではの体験を見込む。

### 6.3 「レビューを求める」画面
- アプリ内に、ユーザーへ**ストアレビュー（評価）を依頼する画面**を実装予定。
- ポジティブな体験直後（例：面接ロールプレイで高スコアが出た、単語を習得した瞬間など）に表示し、好意的なレビューを獲得しやすくする。

> 検討点：表示タイミング・頻度の設計が重要。やりすぎると体験を損なうため、満足度の高い瞬間を起点に、適切な間隔・回数制限を設ける（iOS は `SKStoreReviewController` 等のネイティブ API 利用を前提に設計）。

## 9. 通信フロー例（1セッション）

```
[セッション開始]
[1] frontend が WebSocket で /ws/conversation に接続
[2] frontend がロールプレイ設定（AIキャラ・シーン）を送信
[3] backend が OpenAI Realtime API へ接続、設定をシステムプロンプトに反映
[4] AI の最初のセリフが音声ストリームで返り、frontend で再生
    同時に文字起こしテキストも順次表示

[ユーザーの割り込み]
[5] frontend の VAD がユーザーの発話を検出
[6] frontend が backend へ「割り込み開始」通知
[7] backend が Realtime API へ "cancel" を送信 → AI 発話即停止
[8] ユーザー音声がストリームで backend → Realtime API へ
    リアルタイム文字起こしテキストが frontend に逆流
[9] AI が応答を生成、音声ストリームで frontend へ

[非同期フィードバック]
[10] ユーザーのターン完了時にバックグラウンドで:
     - GPT-5: 文法・表現の訂正
     - Azure Speech: 音素スコア
     - linking 自然さチェック
[11] 結果を WebSocket で frontend へ push
[12] frontend がオーバーレイで表示（会話は止めない）

[ハイライト習得]
[13] ユーザーが画面上の単語/イディオムをハイライト → /api/highlight に登録
[14] 以降の AI 発話のプロンプトに「以下の表現を積極的に使う」指示が混入
[15] AI 発話内で該当単語が赤字でレンダリング
[16] ユーザーがその単語を使った発話を検出するごとに習得度を更新
[17] 習得度が閾値超え → 赤字表示が自然に消える
```

## 13. これまでの経緯

このリポジトリは元々 **「YouTube 字幕翻訳 + クリック解説」** の Chrome 拡張機能として開発を開始した（旧 Mingo）。Step 1 まで実装し、Python による音声DL → Whisper → 翻訳 → クリック解説の CLI まで動作確認済み。

その後、市場分析と機能の差別化検討を経て、

- 字幕翻訳カテゴリには Trancy / Language Reactor などの強力な競合が既に存在し、**真っ向勝負は不利**
- 一方で **「リアルタイム自然会話 × 訂正 × 音素レベル発音採点 × ハイライト習得」** を統合したサービスは存在せず、痛みの強度も高い（発音・会話練習は「便利」ではなく「不安解消」レベルの需要）

と判断し、**AI 英会話練習プロダクトへピボット**した。

旧 Mingo（字幕翻訳）のコードは [Mingo-legacy](https://github.com/Ryotaro-Fujiwara-san/Mingo-legacy) リポジトリに保存している。Whisper / GPT 連携などの実装は新 Mingo にも転用予定。
