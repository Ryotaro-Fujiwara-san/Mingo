# Mingo 仕様書

## 1. 製品概要

Mingo は、**AI との自然な会話**を通じて実践的なスピーキング力を鍛える英語学習プロダクト（多言語対応は MVP 後回し、§3.9 参照）。

ボタン操作を起点としない自然なターンテイキングと、その場での文法・発音フィードバックにより、「会議で発言できない」「面接が怖い」といった**実戦に近いプレッシャー下での発話**を安全に練習できる。相手 AI のパーソナリティや状況を細かく設定できるため、面接・会議・交渉などシーンに合わせた会話練習が可能。

---

## 2. ターゲットと課題

| ターゲット | 解決したい課題 |
| --- | --- |
| 外資・グローバル企業で働く社会人 | 英語の会議で一言も発言できない |
| 転職・就活で英語面接を控える人 | 英語面接が怖い／準備できない |
| 言いたいことが英語で出てこない人 | 会話中に言葉に詰まり、覚えた表現を使えない |
| 発音に自信がない学習者 | 発音が通じない（発音採点は MVP 後回し） |
| 英語以外の言語学習者 | 実践的な会話練習の場がない |

## 3. コア機能

### 3.1 リアルタイム会話・文字起こし
- ユーザーの発言と AI の返答を、**両方リアルタイムで文字起こし**して画面に表示する。
- 会話の流れを目で追えるため、聞き取れなかった箇所もその場で確認できる。

### 3.2 割り込み（インタラプト）対応
- AI が話している途中でも、ユーザーが**自由に割り込んで発言**できる。
- ボタンを押さずに会話が始まり・続く、自然なターンテイキングを実現する。

### 3.3 その場フィードバック（文法）
- **文法**：ユーザーの発言に誤りがあれば、GPT-5 で訂正文を生成し表示する。
- ユーザーのターン完了時にバックグラウンドで実行し、会話を止めずにオーバーレイ表示する。
- **発音採点・リンキング評価は MVP 後回し**（Azure AI Speech + GPT-5 の二段構成。§10 ロードマップ「後回し」参照）。

### 3.4 ロールプレイ設定
- 相手 AI の**パーソナリティ・状況を細かくカスタマイズ**できる。
  - 例：「厳しい外資の面接官」「フランクな同僚」「急いでいるクライアント」など。
- シーン設定（会議・面接・雑談・交渉など）に応じて相手を作り込める。

### 3.5 学習定着システム（ハイライト習得）
- ユーザーがハイライトした単語・イディオムは、相手 AI が返答内で**赤字で積極的に使用**する。
- ユーザーがそれらを使った文を多く発話するほど「**習得した**」とみなし、赤字表示が自然に消えていく。
- 「単語との出会い → 反復露出 → 自分で使う → 定着」を会話の中で完結させる、間隔反復に近い設計。

### 3.6 メモ機能・ヒントボタン
- **メモ機能**：会話中に出会った**知らない単語・表現をメモ**できる。AI の発話・自分の発話どちらからでも登録でき、後から見返せる自分専用の表現帳になる。
- **ヒントボタン**：自分の発話ターン中に画面の「ヒント」ボタンを押すと、**メモ済み表現の中から今の文脈で使えるもの**を GPT-5 がサジェストする。
  - 例：会議で意見を求められて言葉に詰まったとき、過去にメモした `to be honest with you` `that being said` などを「今ここで使える表現」として短い使用例つきで提示。
- 「考え込んで黙ってしまう（フリーズする）」のを防ぎ、**メモした表現を実際の発話で使い切る**ことで定着を後押しする。

### 3.7 深掘り解説（MVP 後回し）
- AI のセリフをクリックすると、**文法・イディオム・類似表現**まで深掘り解説を表示する。
- 「日本語でこう言いたい」と入力すると、**自然な英訳と文法ヒント**を返す。
- 需要検証で ChatGPT / DeepL による代替性が高いと判断したため、MVP では実装しない（§10 ロードマップ「後回し」参照）。

### 3.8 補助機能
- **リピート再生**：AI の発話を聞き直せる。
- **単語タップ発音**（MVP 後回し）：単語をタップすると、その発音が再生される。

### 3.9 多言語対応（MVP 後回し）
- 英語に限らず、複数言語の学習に対応する。
- MVP は英語 × 面接ロールプレイに集中し、勝ち筋が見えてから他言語へ拡張する。

## 4. 競合との差別化ポイント

MVP で勝負する軸（順に優先）:

- **ボタン不要の割り込み型ターンテイキング**：実戦に近い発話プレッシャーを再現。ChatGPT 英会話の「速度が合わない／相槌がない」不満に直撃。
- **細かく作り込めるロールプレイ × 面接特化**：相手のパーソナリティ・状況を自由設定し、特に**英語面接（外資・転職）**で履歴書連動の深掘り質問まで踏み込む（§6.1 を MVP 段階で前倒し検討）。
- **メモ × ヒントボタンで「使える表現」を増やす**：会話中にメモした表現を、発話に詰まった瞬間に「今使える表現」としてサジェスト。インプット（出会い）からアウトプット（実戦使用）までを一本の会話で繋ぐ（Step 6）。
- **ハイライト習得システム**：出会いから定着までを会話内で完結させる独自の学習ループ（Step 5）。

> 音素別発音スコア + linking 検出（ELSA Speak と同領域）は需要検証の結果 MVP 後回し（§10「後回し」参照）。

---

## 5. 要検討事項（実装前に決めるべき点）

**習得判定ロジック**

- 何回／どの精度で使えば「習得」扱いとするか。
- 単純な使用回数のみか、文法的に正しく使えたかも評価対象に含めるか。
- 判定基準によって体験が大きく変わるため、初期からルールを確定させる。

## 6. 将来的な拡張

### 6.1 レジュメ・写真のアップロード
- ユーザーが**レジュメ（履歴書・職務経歴書）や写真**をアップロードできるようにする。
- レジュメをもとに、AI 面接官が**実際の経歴に沿った質問**を投げる、よりパーソナライズされた面接ロールプレイを実現する。
- 写真は会話の話題提供（写真について説明する練習）や、シーン設定の補助素材として活用できる。

> 検討点：アップロードした個人情報（レジュメ・写真）の保存範囲・利用目的・削除手段を明確にし、プライバシーポリシーと UI 上の同意フローを整備する。

### 6.2 ネイティブアプリ化
- 現行の Web ベースから、**スマホアプリ（iOS / Android）**への展開を予定。
- マイク・音声処理との親和性、プッシュ通知による継続利用、オフライン復習などアプリならではの体験を見込む。

### 6.3 「レビューを求める」画面
- アプリ内に、ユーザーへ**ストアレビュー（評価）を依頼する画面**を実装予定。
- ポジティブな体験直後（例：面接ロールプレイで高スコアが出た、単語を習得した瞬間など）に表示し、好意的なレビューを獲得しやすくする。

> 検討点：表示タイミング・頻度の設計が重要。やりすぎると体験を損なうため、満足度の高い瞬間を起点に、適切な間隔・回数制限を設ける（iOS は `SKStoreReviewController` 等のネイティブ API 利用を前提に設計）。

## 9. 通信フロー例（1セッション）

```
[セッション開始]
[1] frontend が WebSocket で /ws/conversation に接続
[2] frontend がロールプレイ設定（AIキャラ・シーン）を送信
[3] backend が OpenAI Realtime API へ接続、設定をシステムプロンプトに反映
[4] AI の最初のセリフが音声ストリームで返り、frontend で再生
    同時に文字起こしテキストも順次表示

[ユーザーの割り込み]
[5] frontend の VAD がユーザーの発話を検出
[6] frontend が backend へ「割り込み開始」通知
[7] backend が Realtime API へ "cancel" を送信 → AI 発話即停止
[8] ユーザー音声がストリームで backend → Realtime API へ
    リアルタイム文字起こしテキストが frontend に逆流
[9] AI が応答を生成、音声ストリームで frontend へ

[非同期フィードバック（文法）]
[10] ユーザーのターン完了時にバックグラウンドで GPT-5 が文法・表現を訂正
[11] 結果を WebSocket で frontend へ push
[12] frontend がオーバーレイで表示（会話は止めない）

[メモ・ヒント]
[13] ユーザーが会話中の単語/表現をメモ → /api/memo に登録
[14] 発話に詰まったらユーザーが「ヒント」ボタンを押す
[15] frontend が直近の会話文脈を /api/expression_hint へ送信
[16] GPT-5 がメモ済み表現から今の文脈で使えるものを選び、短い使用例つきで返す
[17] frontend がサジェストを表示 → ユーザーがそれを使って発話

[ハイライト習得]
[18] ユーザーが画面上の単語/イディオムをハイライト → /api/highlight に登録
[19] 以降の AI 発話のプロンプトに「以下の表現を積極的に使う」指示が混入
[20] AI 発話内で該当単語が赤字でレンダリング
[21] ユーザーがその単語を使った発話を検出するごとに習得度を更新
[22] 習得度が閾値超え → 赤字表示が自然に消える
```

### 後回し（MVP後に検討）

需要検証の結果、いずれも MVP の差別化軸ではなく後回しに変更。番号は付けず、優先度が再浮上した時点でロードマップに組み入れ直す。

| 機能 | 後回し理由 |
| --- | --- |
| 音素レベル発音採点 + リンキング評価（Azure AI Speech + GPT-5 二段構成） | 会話の中核体験（割り込み会話・文法訂正・メモ/ヒント）を固めるのが先。ELSA 等の専用アプリと競合する領域で、MVP の差別化軸から一旦外す |
| 深掘り解説（AI 発言をクリック → 文法・イディオム・類似表現ポップアップ） | ChatGPT / DeepL で代替可能。単体課金の対象になりにくく、面接ロールプレイの精度に時間を回す |
| 日本語→英訳ヒント | 同上。コモディティ化しており差別化にならない |
| 単語タップ発音（TTS + IPA 表示） | あれば嬉しい補助機能だが、無くても MVP の中核体験は成立する |
| 多言語対応（中国語・韓国語・スペイン語など） | 英語×面接で勝つまで広げない。検索ボリュームも英語と桁が違うため後回し |
