# Mingo 仕様書

## 1. 製品概要

Mingo は、**AI との自然な会話**を通じて実践的なスピーキング力を鍛える語学学習プロダクト（英語をはじめ複数言語に最初から対応、§3.7 参照）。

自分で使う言語表現が意味・発音的に自然かどうか、そして能動的に知らなかった表現を使えるようにするサイトが欲しかったため、このプロダクトを作成した。

---

## 2. ターゲットと課題

| ターゲット | 解決したい課題 |
| --- | --- |
| 言いたいことが英語で出てこない人 | 会話中に言葉に詰まり、覚えた表現を使えない |
| 発音に自信がない学習者 | 発音が通じない（音素レベルで採点） |
| 英語以外の言語学習者 | 実践的な会話練習の場がない |

## 3. コア機能

### 3.1 リアルタイム会話・文字起こし
- ユーザーの発言と AI の返答を、**両方リアルタイムで文字起こし**して画面に表示する。
- 会話の流れを目で追えるため、聞き取れなかった箇所もその場で確認できる。

### 3.2 割り込み（インタラプト）対応
- AI が話している途中でも、ユーザーが**自由に割り込んで発言**できる。
- ボタンを押さずに会話が始まり・続く、自然なターンテイキングを実現する。

### 3.3 その場フィードバック（文法・発音）
- **文法**：ユーザーの発言に誤りがあれば、GPT-5 で訂正文を生成し表示する。
- **発音**：音素レベルの発音採点（Accuracy / Fluency / Completeness / Prosody）と単語間のリンキング評価を、**Azure AI Speech + GPT-5 の二段構成**で行う。Azure が音素スコアと break エラーを算出し、GPT-5 がそれを噛み砕いた講評・改善アドバイスに変換する。
- いずれもユーザーのターン完了時にバックグラウンドで実行し、会話を止めずにオーバーレイ表示する。

### 3.4 ロールプレイ設定
- 相手 AI の**パーソナリティ・状況を細かくカスタマイズ**できる。
  - 例：「厳しい外資の面接官」「フランクな同僚」「急いでいるクライアント」など。
- シーン設定（会議・面接・雑談・交渉など）に応じて相手を作り込める。

### 3.5 メモ機能・ヒントボタン（個人ナレッジベース × 意味検索）
- **メモ機能（個人専用ナレッジベース）**：会話中に出会った**知らない単語・表現をメモ**できる。AI の発話・自分の発話どちらからでも登録でき、ユーザーだけの「**個人専用の語彙帳（ナレッジベース）**」になる。各メモには**習得度・最終使用日・間隔反復スコア**などのメタデータを持たせる。
- **ヒントボタン（意味検索ベースの retrieval）**：自分の発話ターン中に「ヒント」ボタンを押すと、**直近の会話文脈をクエリにして、メモ済み表現から「今この場面で使えるもの」を意味検索（embedding）で引き当てる**。
  - キーワード一致ではなく**意味で検索**するのが肝。例：話題が「職場での謝罪」なら、`apology` という単語をメモしていなくても、謝罪系の表現メモ（例 `to be honest with you` `my bad for…`）を意味的に retrieve できる。
  - 検索結果は**メタデータ（習得度・最終使用日・間隔反復スコア）でフィルタ／並べ替え**し、「そろそろ復習すべき」「まだ使えていない」表現を優先。最後に GPT-5 が今の文脈に合わせた短い使用例をつけて提示する。
- これは学習済み LLM の**パラメトリック知識では代替できない**点に価値がある（ユーザー個人の語彙帳はモデルの中に存在しないため）。「考え込んで黙ってしまう（フリーズ）」を防ぎつつ、間隔反復に沿った**能動的想起（active recall）**でメモした表現の定着を後押しする。

### 3.6 補助機能
- **リピート再生**：AI の発話を聞き直せる。

### 3.7 多言語対応
- 英語に限らず、複数言語（中国語・韓国語・スペイン語など）の学習に**最初から対応**する。
- 学習したい言語を選ぶと、その言語でロールプレイ会話・文法／発音フィードバック・メモ／ヒントをそのまま利用できる。

## 4.技術スタック

| 層 | 技術 |
| --- | --- |
| フロントエンド | React + Vite + TypeScript |
| バックエンド | Python + FastAPI + Uvicorn |
| 会話エンジン | OpenAI Realtime API (`gpt-realtime` 系) |
| 発音採点 | Azure AI Speech (Pronunciation Assessment) |
| 文法訂正・発音講評・ヒント生成 | OpenAI GPT-5 |
| メモ意味検索（retrieval） | OpenAI Embeddings (`text-embedding-3-small`) + ベクトル検索（製品化フェーズは Supabase pgvector） |
| DB（製品化フェーズ） | Supabase (PostgreSQL + pgvector + Auth) |
| 決済（製品化フェーズ） | Stripe |
| ホスティング（製品化フェーズ） | Vercel (frontend) + Render/Railway (backend) |

## 6. 通信フロー例（1セッション）

```
[セッション開始]
[1] frontend が WebSocket で /ws/conversation に接続
[2] frontend がロールプレイ設定（AIキャラ・シーン）を送信
[3] backend が OpenAI Realtime API へ接続、設定をシステムプロンプトに反映
[4] AI の最初のセリフが音声ストリームで返り、frontend で再生
    同時に文字起こしテキストも順次表示

[ユーザーの割り込み]
[5] frontend の VAD がユーザーの発話を検出
[6] frontend が backend へ「割り込み開始」通知
[7] backend が Realtime API へ "cancel" を送信 → AI 発話即停止
[8] ユーザー音声がストリームで backend → Realtime API へ
    リアルタイム文字起こしテキストが frontend に逆流
[9] AI が応答を生成、音声ストリームで frontend へ

[非同期フィードバック（文法・発音）]
[10] ユーザーのターン完了時にバックグラウンドで Azure AI Speech が発音を採点し、
     GPT-5 が文法・表現を訂正 + 発音を講評
[11] 結果を WebSocket で frontend へ push
[12] frontend がオーバーレイで表示（会話は止めない）

[メモ・ヒント]
[13] ユーザーが会話中の単語/表現をメモ → /api/memo に登録
[14] 発話に詰まったらユーザーが「ヒント」ボタンを押す
[15] frontend が直近の会話文脈を /api/expression_hint へ送信
[16] backend が会話文脈を embedding 化し、メモ済み表現を意味検索で retrieve
     （習得度・間隔反復スコアでフィルタ）→ GPT-5 が使用例つきで返す
[17] frontend がサジェストを表示 → ユーザーがそれを使って発話
```

## 8. 必要な API キー・サービス

### フェーズ1（プロトタイプ）

| サービス | 用途 | 備考 |
| --- | --- | --- |
| **OpenAI Realtime API** (`gpt-realtime` 系) | 会話の中核（常時マイク ON / 割り込み / 低遅延ストリーミング音声入出力） | OpenAI API キー。**Step 1 から必須**。Realtime はトークン単価が高め、Step 7 でキャッシュ・最適化を要検討 |
| **OpenAI GPT-5** | 文法訂正・発音講評・ヒントボタンの表現サジェスト生成 | 同上 |
| **OpenAI Embeddings API** (`text-embedding-3-small` 系) | メモの意味検索（個人ナレッジベースの retrieval）。**Step 6 から必須** | OpenAI API キー（GPT-5 と共通） |
| **Azure AI Speech** (Pronunciation Assessment) | 発音採点（音素 Accuracy / Fluency / Completeness / Prosody、break エラー）。**Step 5 から必須** | 別途 Azure サブスクリプション。月 5 時間まで無料枠あり |
| **FastAPI / Uvicorn** | バックエンドサーバー | OSS（無料） |
| **React + Vite** | フロントエンド | OSS（無料） |

### フェーズ2（製品化）

| サービス | 用途 | 備考 |
| --- | --- | --- |
| **Supabase** | DB（PostgreSQL + pgvector）+ 認証 + Storage。pgvector でメモの意味検索を本番運用 | 無料枠 500 MB DB / 5 GB Storage |
| **Stripe** | サブスクリプション課金 | テストモードは無料 |
| **Vercel** | フロントエンド・ホスティング | 個人利用は無料 |
| **Render / Railway / Fly.io** | バックエンド・ホスティング | 月 $7 程度から |
